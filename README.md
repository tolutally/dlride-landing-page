# DLride Landing Page

A [Next.js](https://nextjs.org) (App Router) site for DLride, ready to deploy on
[Vercel](https://vercel.com).

## Prerequisites

- Node.js `>=22.13.0`

## Quick Start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Useful Commands

- `npm run dev`: start local development
- `npm run build`: production build
- `npm start`: run the production build locally
- `npm run lint`: lint the project

## Deploying to Vercel

Push this repo to a Git provider and [import it into Vercel](https://vercel.com/new),
or deploy from the CLI:

```bash
npx vercel
```

Vercel auto-detects the Next.js framework and runs `npm run build`.
